# Kevin Zhang — Super Cool Website

A student portfolio website based on Kevin's original hand-drawn plan.

## Features
1. Particle Simulation
2. Homework Tracker / To-do List
3. Study Timer
4. Reaction Game
5. Geometry Visualizer
6. Filterable Gallery
7. Click Counter
8. Theme Changer
9. Good Luck Game (virtual, for fun only — no money or prizes)

## Run on your computer
Open `index.html` in Chrome, Edge, Firefox, or Safari.

## Main files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — all interactive features
- `assets/kz-profile.svg` — KZ profile logo
- `Kevin_Zhang_Original_Sketch.jpg` — original design sketch
- `Kevin_Super_Cool_Website_GitHub_Instructions.docx` — publishing guide

## Customize
Search the code for headings such as `Particle Simulation`, `Homework Tracker`, or `gallery` and replace text or data. To add real gallery photos, create an `assets/photos/` folder and update the gallery section in `script.js`.
